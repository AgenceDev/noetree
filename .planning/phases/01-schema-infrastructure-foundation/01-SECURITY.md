# Phase 1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary                                                       | Description                                                                                                                                       | Data Crossing                             |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| Convex client → public `query` functions                       | `getSubscription`/`getCredits`-family queries are callable directly from any authenticated (or unauthenticated) Convex client call                | Subscription status, AI credit balance    |
| Convex function → Convex function                              | `internalMutation`/`internalQuery` handlers are only reachable from server-side Convex code (webhook/AI-action handlers), never from a client SDK | Subscription writes, credit writes        |
| Browser → Next.js middleware (`proxy.ts`)                      | Every incoming request is evaluated by `clerkMiddleware` before reaching a route handler                                                          | Session/auth state                        |
| npm registry → local `node_modules`                            | Third-party code (`stripe`, `@stripe/stripe-js`) executed in the build/runtime                                                                    | N/A (supply chain)                        |
| Repo (git-tracked) ↔ local secrets (`.env.local`, git-ignored) | `.env.example` must never cross into containing real secret values                                                                                | Stripe API keys, webhook signing secrets  |
| Local machine → Stripe API                                     | `STRIPE_SECRET_KEY` (test mode) transmitted over HTTPS via curl Basic auth for product/price provisioning                                         | Stripe secret key                         |
| Vercel dashboard ↔ deployed Next.js runtime                    | Env vars set in Vercel become `process.env.*` in every deployment scope                                                                           | Stripe secret key, webhook signing secret |
| Stripe Dashboard ↔ webhook endpoints                           | Each endpoint's signing secret is the sole authenticity proof for inbound webhook calls                                                           | Webhook signing secrets                   |
