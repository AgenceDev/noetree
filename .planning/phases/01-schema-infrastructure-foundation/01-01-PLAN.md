<threat_model>

## Trust Boundaries

| Boundary                                 | Description                                                                                                                      |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Convex client → public `query` functions | `getSubscription`/`getCredits` are callable directly from any authenticated (or unauthenticated) Convex client call              |
| Convex function → Convex function        | `internalMutation`s are only reachable from server-side Convex code (future webhook/AI-action handlers), never from a client SDK |

## STRIDE Threat Register

| Threat ID | Category               | Component                                                                                | Disposition | Mitigation Plan                                                                                                                                                                                                           |
| --------- | ---------------------- | ---------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-01-01   | Tampering              | `getSubscription`/`getCredits` args                                                      | mitigate    | Convex `v.string()` argument validators reject malformed/non-string `clerkUserId` at the framework level before the handler runs (ASVS V5) — no hand-rolled validation needed                                             |
| T-01-02   | Elevation of Privilege | `upsertSubscription`, `deleteSubscription`, `deductCredit`, `resetCredits`, `addCredits` | mitigate    | Declared as `internalMutation` (not `mutation`) — Convex enforces these are only invocable from other Convex functions, never directly from a client, closing off unauthorized direct writes to subscription/credit state |
| T-01-03   | Information Disclosure | Stub handler bodies (`throw new Error(...)`)                                             | accept      | No real data read/written yet in Phase 1 — handlers are unreachable no-ops until Phase 2 wires real logic; zero data-exposure surface at this stage                                                                       |

</threat_model>
