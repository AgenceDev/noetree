<threat_model>

## Trust Boundaries

| Boundary                   | Description                                                                                         |
| -------------------------- | --------------------------------------------------------------------------------------------------- |
| client → Server Action     | The pricing page (untrusted client) invokes `createCheckoutSession`; only `locale` crosses as input |
| Server Action → Stripe API | Server-side, holds STRIPE_SECRET_KEY, writes clerkUserId into Stripe metadata                       |

## STRIDE Threat Register

| Threat ID | Category               | Component                                               | Disposition | Mitigation Plan                                                                                                                                                                                    |
| --------- | ---------------------- | ------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-03-02   | Spoofing               | `createCheckoutSession` clerkUserId                     | mitigate    | clerkUserId is sourced exclusively from `(await auth()).userId` server-side; it is never accepted as a client-passed argument, so a client cannot attribute a payment to another account (ASVS V4) |
| T-03-01   | Tampering              | `locale` param interpolated into success_url/cancel_url | mitigate    | Validate `locale` against `routing.locales` and default on miss before building any redirect URL — prevents open-redirect / malformed Stripe URLs (ASVS V5)                                        |
| T-03-04   | Denial of Service      | duplicate/overlapping subscriptions from stale tabs     | mitigate    | D-08 active-status short-circuit returns before any Stripe call when a subscription is already active                                                                                              |
| T-03-05   | Information Disclosure | STRIPE_SECRET_KEY                                       | accept      | Key lives only inside the `"use server"` module (never shipped to the client bundle); standard Next.js Server Action isolation                                                                     |

</threat_model>
