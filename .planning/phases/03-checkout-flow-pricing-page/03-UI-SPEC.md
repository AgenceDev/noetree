## Design System

| Font              | Geist Sans (`--font-geist-sans`), body + headings. Geist Mono unused this phase. (source: `app/[locale]/layout.tsx`)   |

**Existing tokens reused (no new tokens defined this phase):** `--background`, `--foreground`, `--card`, `--card-foreground`, `--secondary`, `--muted`, `--muted-foreground`, `--primary` (#7e10b2), `--primary-foreground`, `--border`, `--destructive`, `--radius` — all from `app/globals.css`.

**Layout note (from CONTEXT.md D-01):** `/pricing` and `/checkout/success` do NOT render inside the authenticated app shell (no `AppSidebar`, no `Header`). They need a separate lightweight wrapper — a centered, max-width content column (`max-w-3xl` for pricing, `max-w-md` for success), no sidebar, no `useHeaderConfig` title injection. They are still wrapped by the global `ClerkProvider` / `ConvexClientProvider` / `ThemeProvider` / `NextIntlClientProvider`. **Achieving this requires decomposing the root layout, not merely adding a route-group layout:** a nested `(marketing)` layout composes INSIDE the root and cannot remove chrome the root already rendered (route groups change URL grouping, not layout inheritance). Plan 03-05 therefore keeps the global providers in the root `app/[locale]/layout.tsx` and moves the app-shell chrome into a new `app/[locale]/(app)/layout.tsx` route group wrapping only the authenticated routes; the chrome-free `(marketing)` shell then just adds the centered wrapper.

## Spacing Scale

Declared values (must be multiples of 4), matching existing app-wide convention (no `tailwind.config.*` overrides found — default Tailwind v4 scale in use):

| Token | Value | Usage                                                               |
| ----- | ----- | ------------------------------------------------------------------- |
| xs    | 4px   | Icon-to-label gaps inside feature list rows                         |
| sm    | 8px   | Gap between checkmark icon and feature text                         |
| md    | 16px  | Default spacing between plan card sections (price → features → CTA) |
| lg    | 24px  | Padding inside each pricing card (`p-6`)                            |
| xl    | 32px  | Gap between the Free and Pro cards in the comparison grid           |
| 2xl   | 48px  | Space between page heading and the plan cards grid                  |
| 3xl   | 64px  | Top/bottom page padding on `/pricing`                               |

Exceptions:

- Primary CTA button ("Upgrade to Pro") uses `h-11` (44px) instead of the app's default `h-10` (40px) control height — this is the single conversion-critical action on the page and gets a larger touch target. All other buttons on these two pages (e.g. success page's "Refresh") use the existing `h-10` default.

## Typography

3 sizes + 1 display size, 2 weights only — consistent with existing usage (`components/Header.tsx` uses `font-semibold`, `app/[locale]/page.tsx` uses `text-lg` / `text-sm font-medium`):

| Role    | Size               | Weight         | Line Height |
| ------- | ------------------ | -------------- | ----------- |
| Body    | 16px (`text-base`) | 400 (regular)  | 1.5         |
| Label   | 14px (`text-sm`)   | 400 (regular)  | 1.5         |
| Heading | 20px (`text-xl`)   | 600 (semibold) | 1.2         |
| Display | 32px (`text-3xl`)  | 600 (semibold) | 1.2         |

Usage mapping:

- **Display** — `/pricing` page hero title ("Simple, transparent pricing") only.
- **Heading** — plan card titles ("Free", "Pro"), success-page confirmation heading.
- **Body** — plan price line, feature list items, success-page body copy.
- **Label** — "billed monthly" subtext, plan card badges ("Current plan"), fine print.

No third weight (no "medium"/500) — use semibold (600) for emphasis, regular (400) otherwise, matching the rest of the app.
