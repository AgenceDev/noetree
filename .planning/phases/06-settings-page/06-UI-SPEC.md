## Spacing Scale

Declared values (must be multiples of 4) — matches Tailwind's default scale already in use project-wide (verified in `pricing/page.tsx`, `notes/page.tsx`):

| Token | Value | Usage                                                                                             |
| ----- | ----- | ------------------------------------------------------------------------------------------------- |
| xs    | 4px   | Icon-to-label gap (e.g. Settings nav icon, status dot)                                            |
| sm    | 8px   | Compact spacing inside a Card row (label ↔ value)                                                 |
| md    | 16px  | Default spacing between Card header/content, form field gaps                                      |
| lg    | 24px  | Card internal padding (`CardContent` default), gap between Plan/Credits sections' internal groups |
| xl    | 32px  | Gap between the stacked Plan Card and Credits Card (D-10)                                         |
| 2xl   | 48px  | Page-level top padding under the app header                                                       |
| 3xl   | 64px  | Not used this phase (no full-page hero)                                                           |

Exceptions: none. Do not introduce arbitrary pixel values (e.g. `mt-[13px]`) anywhere in this phase's components.

## Typography

Derived directly from existing, already-deployed patterns (`pricing/page.tsx` CardTitle/heading/body usage) — reuse these exact Tailwind classes, do not invent new sizes.

| Role                 | Size | Weight         | Line Height | Tailwind class                                                                                                    |
| -------------------- | ---- | -------------- | ----------- | ----------------------------------------------------------------------------------------------------------------- |
| Body                 | 16px | 400 (regular)  | 1.5         | `text-base font-normal`                                                                                           |
| Label / secondary    | 14px | 400 (regular)  | 1.5         | `text-sm text-muted-foreground` — used for renewal/cancel status line, top-up date/amount rows                    |
| Heading (Card title) | 20px | 600 (semibold) | 1.2         | `text-xl font-semibold` — "Plan" / "Credits" card titles, mirrors `CardTitle` on pricing page                     |
| Display (page title) | 30px | 600 (semibold) | 1.2         | `text-3xl font-semibold` — Settings page `<h1>`, mirrors Pricing page's `<h1 className="text-3xl font-semibold">` |

Exactly 4 sizes, exactly 2 weights (400/600) — no `font-bold` (700) or `font-medium` (500) introduced this phase.

## Copywriting Contract

Voice matches existing locked copy (`Pricing` namespace, `notes` delete-confirmation pattern) — reuse exact strings where the same concept already exists; new strings follow the same terse, direct register.

| Element                                                          | Copy                                                                                                                                                                                                                  |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Primary CTA (Free user, SET-03)                                  | "Upgrade to Pro" — **reuse the exact existing `Pricing.upgradeCta` string**, links to `/pricing` (plain `Link`, no new Server Action per D-11)                                                                        |
| Secondary CTA (Pro user, active)                                 | "Cancel subscription" (destructive-styled trigger, opens `AlertDialog`)                                                                                                                                               |
| Secondary CTA (Pro user, pending cancellation)                   | "Resume subscription" (accent-styled, D-02)                                                                                                                                                                           |
| Cancel confirmation — `AlertDialogTitle`                         | "Cancel your subscription?"                                                                                                                                                                                           |
| Cancel confirmation — `AlertDialogDescription`                   | "You'll keep Pro access until [renewal date]. You can resume anytime before then."                                                                                                                                    |
| Cancel confirmation — `AlertDialogCancel` (dismiss)              | "Keep subscription"                                                                                                                                                                                                   |
| Cancel confirmation — `AlertDialogAction` (confirm, destructive) | "Cancel subscription"                                                                                                                                                                                                 |
| Status copy — active, not cancelling                             | "Renews on [date]"                                                                                                                                                                                                    |
| Status copy — pending cancellation (**locked, D-03**)            | "Cancels on [date]"                                                                                                                                                                                                   |
| Status copy — Free plan                                          | "Free plan"                                                                                                                                                                                                           |
| Empty state — top-up history (no purchases yet)                  | Heading: "No top-ups yet" / Body: "Your AI credit purchases will appear here once you buy a top-up."                                                                                                                  |
| Error state — cancel/resume action fails                         | "Something went wrong updating your subscription. Please try again, or contact support if this keeps happening." (inline, near the action button — not a full-page error)                                             |
| Destructive confirmation                                         | Cancel subscription: modal confirm-or-abort via `AlertDialog` (D-01) — no type-to-confirm, single confirm/cancel button pair is sufficient since Pro access is not lost immediately (low-severity destructive action) |

Date formatting: use `Intl.DateTimeFormat`/`toLocaleDateString()` (no new date library — none installed project-wide). Format: medium style, e.g. "July 15, 2026" (`{ year: "numeric", month: "long", day: "numeric" }`), locale-aware via `next-intl`'s active locale.

**Pitfall reminder (from RESEARCH.md):** `subscription.currentPeriodEnd` is stored in Unix **seconds**, not ms — always render via `new Date(currentPeriodEnd * 1000)`. Any rendered date the checker/auditor sees should be a real future date, never a 1970 date.
