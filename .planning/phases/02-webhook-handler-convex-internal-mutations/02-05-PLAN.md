<objective>
Create `app/api/webhooks/stripe/route.ts` — the first file under `app/api/` in this repo, and the sole Stripe-facing HTTP entry point. It reads the raw request body, verifies the Stripe signature, and — only for `checkout.session.completed` — retrieves the full Stripe Subscription object (a Checkout Session does not carry `status`/period-end fields natively) before forwarding to the Convex dispatcher action created in Plan 02-04, mapping the action's outcome to the correct HTTP status code.

Purpose: Fulfills ROADMAP SC4/SC5 — the HTTP-layer status-code contract (400 for bad signatures/auth failures, 500 for genuine failures, 200 otherwise) is entirely this file's responsibility; the Convex layer (Plan 02-04) only throws or returns sentinels, it has no concept of HTTP status codes.
Output: `app/api/webhooks/stripe/route.ts` implementing `POST`; `app/api/webhooks/stripe/route.test.ts` green via Vitest with `stripe` and `convex/browser` mocked (no live network calls in tests).
</objective>
